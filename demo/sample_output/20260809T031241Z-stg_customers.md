# Incident Report: stg_customers Failure

**Date:** 2026-08-09T03:12:41Z  
**Model:** stg_customers  
**Status:** Investigated

## Summary
The dbt model `stg_customers` failed because it attempted to select a column `customer_email` which no longer exists in the upstream table `raw.customers`.

## Root Cause
Upstream table raw.customers renamed customer_email to email; stg_customers.sql still selects customer_email.

## Proposed Fix
- **SQL Change:** Update `models/staging/stg_customers.sql` to select `email` instead of `customer_email`.
- **Guardrail:** Add a dbt schema contract or a source freshness test to the `raw.customers` source definition to catch schema drifts earlier.

## Investigation Details
- **Error Class:** Missing Column
- **Live Schema (raw.customers):** The column `email` was found, confirming the rename from `customer_email`.
