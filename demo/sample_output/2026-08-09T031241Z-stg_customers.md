# Incident Report: stg_customers Failure

## Summary
The dbt model `stg_customers` failed because it referenced a non-existent column `customer_email`. The upstream table `customers` uses `email` instead.

## Root Cause
Upstream table `customers` uses `email`; `stg_customers.sql` incorrectly references `customer_email`.

## Proposed Fix
Update `models/staging/stg_customers.sql` to select `email` instead of `customer_email`.

## Guardrail
Implement a dbt schema test (e.g., `not_null` or `unique`) on the source to validate column existence during the CI process.
